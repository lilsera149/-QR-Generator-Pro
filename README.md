# 📱 QR Code Automation PRO

Современное десктопное приложение на Python для автоматизации создания дизайнерских и брендированных QR-кодов. Проект разработан с использованием кастомного графического интерфейса и алгоритмов высокоточной генерации кодов, подходящих для считывания любыми смартфонами.

## ✨ Основные фичи:
- **Premium UI:** Интерфейс приложения выполнен в современном темном стиле благодаря библиотеке `CustomTkinter`.
- **Дизайнерские QR-коды:** Использование скругленных модулей (`RoundedModuleDrawer`) вместо стандартных квадратных пикселей.
- **Фирменные цвета:** Возможность выбора цвета под брендбук компании (Синий, Зеленый, Красный, Классический черный).
- **Высокая отказоустойчивость:** QR-коды генерируются с максимальным уровнем коррекции ошибок (`ERROR_CORRECT_H`), что позволяет коду считываться даже при повреждении или наложении логотипа.
- **Автоматизация сохранения:** Приложение автоматически валидирует ссылки, создает изолированную директорию `QR_Outputs` и сохраняет файлы с безопасными именами.

## 🛠️ Стек технологий:
- **Язык:** Python 3.10+
- **GUI:** CustomTkinter
- **QR Core:** Qrcode (StyledPilImage, SolidFillColorMask)
- **Image Processing:** Pillow (PIL)

## 🚀 Запуск проекта:

1. Клонируйте репозиторий:
```bash
git clone https://github.com
```

2. Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```
